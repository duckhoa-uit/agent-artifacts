# Security policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.
Older releases may not receive backports.

## Reporting a vulnerability

Please report suspected vulnerabilities through a
[private vulnerability report](https://github.com/duckhoa-uit/agent-artifacts/security/advisories/new).
Do not open a public issue or include credentials, API keys, tokens, private
artifact URLs, or customer data in a report.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days. Fix and
disclosure timelines depend on severity and complexity.

If a credential may have been exposed, revoke or rotate it immediately before
submitting the report.
